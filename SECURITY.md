# Xavfsizlik siyosati (Security Policy)

Ushbu loyiha foydalanuvchilarga va hamkorlarga xavfsizlik masalalarini hal qilishda ochiq va xavfsiz yondashishni maqsad qilib qo'yadi. Agar sizda ushbu loyihada xavfsizlikka oid muammo, zaiflik yoki potentsial tahdid topilgan bo'lsa, iltimos quyidagi tartibga rioya qiling.

## Xavfsizlikka oid xabar berish

Kechiktirishdan qochish uchun xatolikni topganingizda, uni ochiq umumiy ma'lumot sifatida e'lon qilmasdan oldin bizga xabar bering.

Bizga quyidagilarni yuboring:

- muammoning tasviri va ta'rifi
- ta'sir qilishi mumkin bo'lgan komponent yoki skript nomi (`netrecon.py`, `netrecon.sh` va boshqa)
- qanday qilib muammo takrorlanishi yoki sinab ko'rilishi
- ta'sir qilish darajasi va mumkin bo'lgan oqibatlar
- agar mavjud bo'lsa, muammoni qanday cheklash yoki vaqtincha oldini olish haqida takliflar

## Xabar yuborish usuli

Iltimos, xavfsizlik muammalari haqida to'g'ridan-to'g'ri GitHub Issues orqali emas, balki quyidagi usullardan birini ishlatib bizga xabar bering:

- GitHub Security Advisories (eng maqsadga muvofiq)
- Email orqali: [qatorni kiriting] (agar email manzili mavjud bo'lsa)

Agar umumiy GitHub Issues bo'limi ochiq bo'lsa ham, xavfsizlik muammolari haqida xabar berish uchun uni ochiq e'lon qilmang; buning o'rniga maxfiy ma'lumotlarni yetkazib berish uchun tegishli xavfsizlik kanallaridan foydalaning.

## O'qishga qabul qilish va javob berish vaqti

- Xavfsizlik hisobotini qabul qilishga harakat qilamiz.
- Hisobotni ko'rib chiqish va tekshirish uchun zarur vaqt ajratamiz.
- Agar muammoning aniqligi tasdiqlangan bo'lsa, biz uni tuzatish bo'yicha ishlaymiz.
- Uzoq muddatli yoki murakkab holatlar uchun biz sizga yangilanishlar kiritamiz.

## Hisobot beruvchilar uchun ko'rsatmalar

- Hisobotni ommaga e'lon qilmang.
- Buzilish yoki zararli ishlatishni tasdiqlashdan oldin, eskirish yoki to'liq ta'sirni ko'rsatish maqsadida qo'shimcha tekshiruvlarni amalga oshirmang.
- Faqat sinov uchun ruxsat berilgan va sizga tegishli bo'lgan tarmoqlar yoki qurilmalar ustida tekshiruv o'tkazing.
- O'zingizning xavfsizlik hisobotingiz orqali boshqa foydalanuvchilar yoki tashkilotlarga potentsial xavf tug'dirmang.

## Yordam va himoya kerak bo'lganda

Ushbu loyiha faqat mahalliy tarmoq va ta'lim maqsadlari uchun mo'ljallangan bo'lib, unga ruxsatsiz kirish yoki zararli ishlatish qattiq man etiladi. Agar xavfsizlikka oid muammalarni topgan bo'lsangiz yoki aniq tasdiqlangan zaiflikni aniqlagan bo'lsangiz, iltimos u haqida tezkor xabar bering.

## Ishlatilgan maqsadlar

Ushbu loyiha faqat quyidagi miqdorda ishlatilishi tavsiya etiladi:

- ruxsat berilgan ichki tarmoq sinovlari
- laboratoriya muhitlari
- ta'lim va ilmiy tadqiqotlar
- mudofaa maqsadli xavfsizlik tekshiruvlari

## Boshqa ma'lumotlar

Bu siyosat loyihaning rivojlanishi davomida yangilanishi mumkin. O'zgartirishlar GitHub repositoriyadagi ushbu fayl orqali ko'rsatiladi.

Agar xavfsizlik xabarini yuborish bo'yicha aniq yo'lni bilishni xohlasangiz, Iltimos, GitHub Security Advisories yoki admin bilan bog'laning.
